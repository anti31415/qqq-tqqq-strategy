# Contributing

Thank you for helping improve this research project.

Every pull request should state the data source and date range, parameters, execution and transaction-cost assumptions, command used, and validation result. Separate observed facts from model assumptions and label simulated results clearly.

Keep secrets, account state, local logs, caches, and raw vendor data out of commits. Prefer small, reviewable changes and add a reproducible check when changing strategy logic.

Use Issues for research questions, data-quality concerns, bug reports, and proposals. This project is educational and does not provide investment advice.
